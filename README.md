# AniBox tvOS

[AniBox](https://github.com/FNOSP/AniBox)（飞牛影视第三方客户端）的 **Apple TV（tvOS）原生移植版**。SwiftUI 重写，液态玻璃（tvOS 26 `glassEffect`，旧系统回退毛玻璃），针对 Siri Remote 焦点与手势优化，MPV 内核（MPVKit）播放。

> 非飞牛官方出品，与飞牛官方无关联。基于 AGPL-3.0 开源，按原样提供、无担保。

## 安装（侧载）
1. 打开本仓库 **Releases** 或 **Actions → 最新运行 → Artifacts**，下载 `AniBoxTV-unsigned.ipa`。
2. 用 Sideloadly / AltStore / Xcode 等工具以你自己的 Apple ID 重签后安装到 Apple TV。

## Siri Remote 操作
| 场景 | 操作 |
|---|---|
| 所有页面 | 滑动移动焦点，点按进入，菜单键返回 |
| 播放中 | 点按 / 播放键：暂停继续；左右：快退快进（步长可设）|
| 播放中 | 上：进入进度拖动模式（左右大步移动，点按确认）|
| 播放中 | 下 或 长按：字幕 / 音轨 / 弹幕 / 倍速 / 版本 / 片头片尾 / 选集面板 |
| 播放中 | 菜单键：先收面板，再隐藏控制条，再退出 |
